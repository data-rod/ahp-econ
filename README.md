# Painel AHP — Contraste de bordas no Cerrado

Consulta a especialistas para avaliar o contraste entre 13 classes vizinhas e a Vegetação Natural Secundária no bioma Cerrado, por meio de 78 comparações pareadas com a escala clássica do AHP.

[Acessar o formulário](https://data-rod.github.io/ahp-econ/)

## Como participar

Informe seus dados profissionais, leia as informações de participação e responda às comparações. Ao finalizar, exporte o arquivo JSON e envie-o como anexo para **rodrigo.neto@inpe.br**, em até 15 dias após receber o convite.

As respostas ficam no navegador até a exportação. O formulário não as envia automaticamente. Não publique o JSON: ele contém sua identificação.
